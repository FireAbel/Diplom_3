# Тестирование веб-приложения Stellar Burgers

## Описание проекта
Проект содержит автоматизированные тесты для веб-приложения Stellar Burgers, написанные с использованием:
- Python
- Selenium WebDriver
- Pytest
- Allure для отчетов
- Page Object Model

## Структура проекта
```
├── locators/           # Локаторы элементов
├── pages/             # Page Object классы
├── tests/             # Тесты
├── conftest.py        # Конфигурация тестов
├── requirements.txt   # Зависимости
└── README.md         # Документация
```


## Запуск тестов
### Запуск всех тестов
```bash
pytest tests/ --alluredir=./allure-results
```

### Запуск тестов в определенном браузере
```bash
pytest tests/ --browser=chrome
pytest tests/ --browser=firefox
```

## Генерация отчета Allure
```bash
allure serve allure-results
```

## Тестируемый функционал
1. Восстановление пароля
   - Переход на страницу восстановления
   - Ввод почты и восстановление
   - Показать/скрыть пароль

2. Личный кабинет
   - Переход в личный кабинет
   - История заказов
   - Выход из аккаунта

3. Основной функционал
   - Навигация по конструктору
   - Лента заказов
   - Детали ингредиентов
   - Оформление заказа

4. Лента заказов
   - Детали заказа
   - История заказов
   - Счетчики заказов
